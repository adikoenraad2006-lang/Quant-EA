The loop

8 seconds: 2s to build, 4.7s of stillness, then every cue leaves the way it came in and the cycle restarts clean — no snap. The photograph breathes on its own 16s cycle so the reset never lands on a hard cut.

Exporting

Each cut is a real pixel ratio, so a screen recording of one unit is the deliverable. Hit Restart first — all four run off one clock, so they stay in step. Type is set in cqi, meaning every cut holds its proportions at 1080px or at thumbnail size.
